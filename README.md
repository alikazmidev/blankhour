# Zenith

**A simple new tab for better focus and steady progress.**

Zenith is a free browser extension that turns your new tab into a calm space for your daily goals. It helps you build habits, stay focused and see how much progress you have made.

> **Beta release: v0.1.0**
>
> Zenith is still in development. You may find bugs or unfinished features. Feedback, suggestions and bug reports are welcome.

## Features

- A minimal new tab with a clock, search bar and optional quick links
- Daily goals and habits with custom schedules
- Progress tracking and charts
- Focus Mode that blocks websites you choose
- Focus sessions with custom timers, optional breaks and saved focus time
- Reminders when you try to visit a blocked website
- Optional sticky notes and a small focus mascot
- Daily quotes and greetings with your name
- Light, dark and custom themes

## How to install

Zenith is **not on the Chrome Web Store yet**. You can install the beta manually in Chrome, Brave or Edge.

1. On GitHub, click **Code** and then **Download ZIP**. You can also download the ZIP from **Releases**, if available.
2. Extract the ZIP to a folder on your computer.
3. Open your browser's extensions page:
   - Chrome: `chrome://extensions`
   - Brave: `brave://extensions`
   - Edge: `edge://extensions`
4. Turn on **Developer mode**.
5. Click **Load unpacked**.
6. Select the folder that contains `manifest.json`.
7. Open a new tab to start using Zenith.

Keep the extracted folder on your computer. The browser needs it to run the extension.

## Getting started

1. Open **Settings** to choose your theme, time format and name.
2. Add a goal and set the days you want to work on it.
3. Tick off your habits as you complete them.
4. Add distracting websites to your **Focus Mode** blocklist.
5. Start a focus session or use the Pomodoro timer. You can pause or end a session early and save the time you focused.
6. Visit **Progress** to review your habits, focus time and detected distraction attempts.

## Updating Zenith

Unpacked extensions do not update automatically.

1. Export a backup from Zenith's Settings before updating.
2. Download and extract the newer version.
3. Replace the files in your existing extension folder.
4. Open your extensions page and click **Reload** on Zenith.

If you remove the extension and install it again, your saved data may be lost. Export a backup first and import it after reinstalling.

## Privacy

Zenith is designed to save your goals, notes, settings and progress locally in your browser. The extension needs certain browser permissions to block the sites you add and track detected attempts to visit them. Review the permissions before installing.
